## Prerequisites

Before testing, ensure the following setup is ready:

| # | Requirement | Ready? |
|---|-------------|--------|
| 1 | Minimum **2 Android phones** (3 preferred for mesh relay tests) | ☐ |
| 2 | All devices have NeighbourNet v1.1 installed (debug APK or dev build) | ☐ |
| 3 | Bluetooth and WiFi enabled on all devices | ☐ |
| 4 | Location services enabled on all devices | ☐ |
| 5 | All devices have granted **Nearby Devices**, **Location**, **Camera**, **Microphone**, and **Storage** permissions | ☐ |
| 6 | Devices are **NOT connected to the internet** (airplane mode + BT/WiFi on) to simulate offline mesh | ☐ |
| 7 | At least one device has images in gallery for image transfer tests | ☐ |
| 8 | Devices have mesh running and can see each other (verify on Mesh Status screen) | ☐ |

### Device Layout for Tests

```
[Device A] <--BT/WiFi--> [Device B] <--BT/WiFi--> [Device C]

- A ↔ B: Within direct range (same table / within 3 meters)
- A ↔ C: NOT in direct range (use B as relay node)
  OR all three in range but test mesh relay by targeting TTL behavior
```
